# Рус тили дафтари

Ўзбек тилида сўзлашувчилар учун рус тилини ўрганиш иловаси: алифбо, мавзулар бўйича луғат,
тайёр иборалар, грамматика ва такрорлаш машқлари.

**Сайт:** https://xudoyberdiyevkomolxoja44-arch.github.io/rus-tili-daftari/

## Нималар бор

- **Режа** — 90 кунлик дастур: кунлик топшириқлар, 3 та ойлик блок ва чорак имтиҳони. Кейинги кун барча топшириқ бажарилгач очилади.
- **Машқ** — карточка, тўрттадан танлаш ва ёзиш режимлари. Ёзиш режимида экранда ЙЦУКЕН
  клавиатураси чиқади, шунинг учун қурилмада русча клавиатура бўлмаса ҳам ишлайди.
- **Такрорлаш тизими** — Лейтнер усули: билган сўз 1 → 2 → 4 → 7 → 14 → 30 кундан сўнг,
  билинмаган сўз эса дарҳол қайтади.
- **Луғат** — 11 мавзу, 178 сўз. Ҳар бирида урғу қизил белгиланган ва ҳақиқий талаффузи
  ёзилган (`молоко́` → «малако́»).
- **Иборалар** — 7 вазият бўйича 36 та тайёр гап; улар ҳам такрорлаш тизимига киради.
- **Алифбо** — 33 ҳарф, мисол сўзлар овоз билан.
- **Грамматика** — 9 та асосий қоида, ўзбек тили билан қиёсланган.

Овоз браузернинг нутқ синтезатори (`speechSynthesis`) орқали чиқади — қурилмада рус овози
ўрнатилган бўлиши керак.

## Файллар

| Файл | Вазифаси |
| --- | --- |
| `rus-tili-daftari.html` | **Ягона манба.** Барча ўзгартириш шу файлда қилинади. |
| `build.mjs` | Манбадан мустақил сайт нусхасини йиғади. |
| `docs/` | Йиғилган сайт — GitHub Pages шу папкадан тарқатади. |
| `docs/sw.js` | Оффлайн ишлаши учун service worker. |
| `docs/manifest.webmanifest` | Телефон бош экранига ўрнатиш учун манифест. |

`docs/index.html` — йиғма файл, уни қўлда таҳрирламанг: кейинги йиғишда ўчиб кетади.

## Ўзгартириш киритиш

```bash
node build.mjs          # docs/ ни янгилайди
git add -A && git commit -m "янгиланиш" && git push
```

Push'дан бир-икки дақиқа кейин сайт янгиланади. Service worker эски нусхани ушлаб қолмаслиги
учун `build.mjs` ҳар сафар кэш версиясини алмаштиради.

Маҳаллий текшириш:

```bash
python -m http.server 8787 --directory docs
```

## Телефонга ўрнатиш

Сайтни телефон браузерида очиб, менюдан **«Bosh ekranga qo'shish» / «Добавить на главный
экран»** ни танланг. Шундан кейин илова алоҳида дастур сифатида очилади ва интернетсиз ҳам
ишлайди.

Натижалар ҳар бир қурилманинг ўз хотирасида (`localStorage`) сақланади.
